# สร้างเกมส์ Find-My-Hat เพื่อค้นหาหมวกที่ซ่อนอยู่ในแผนที่
 
วัตถุประสงค์ในการออกแบบ (Design Objectives)

โปรเจกต์ **Find Your Hat** ทดสอบการเรียนรู้และฝึกฝนทักษะการเขียนโปรแกรม

1. **2D Grid & Spatial Navigation**: 
   เพื่อศึกษาการจัดการตาราง 2 มิติ การคำนวณทิศทางการเคลื่อนที่ตามพิกัด (Row/Column) และการทำ Boundary Checking เพื่อป้องกันไม่ให้ผู้เล่นเคลื่อนที่ออกนอกขอบเขตตาราง

2. **Procedural Level Generation**:
   เพื่อใช้อัลกอริทึมการสุ่มสร้างฉากโดยใช้อัตราส่วนความน่าจะเป็น (Percentage Density) ช่วยให้สร้างระดับความยากและอุปสรรคที่แตกต่างกันในทุกๆ การเล่น

3. **OOP & State Management**:
   เพื่อฝึกการออกแบบโปรแกรมด้วย Object-Oriented Programming โดยซ่อนการจัดการ Game Loop, State และ User Interaction ไว้ภายใน Class เพื่อให้โครงสร้างโค้ดสะอาดและเข้าใจง่าย

ขั้นตอนการดำเนินการ และ การเล่น 
1. ติดตั้ง npm install prompt-sync
2. เรียกใช้ prompt-sync เพื่อรับค่าการกดปุ่มบนคีย์บอร์ดของผู้เล่น
3. กำหนดให้สัญลักษณ์ หมวก = '^'
4. กำหนดให้สัญลักษณ์ hole = 'O';
5. กำหนดให้ fieldCharacter = '░'
6. กำหนดให้ pathCharacter = '*'
7. กำหนดจุดเริ่มต้นที่ column = 0, row = 0.
8. ใช้คำสั่ง match.random เพื่อสร้างแผนที่, ตำแหน่งหลุม และ ตำแหน่งวางหมวก แบบสุ่ม.
9. ประการตัวแปร hatRow เพื่อแสดงตำแหน่งหมวกในแนวนอน
10. ประกาศตัวแปร, hatCol เพื่อแสดงตำแหน่งหมวกในแนวตั้ง
11. สร้างตาราง 2D ขนาด height x width เติมด้วย fieldCharacter ทั้งหมด
12. w/a/s/d, q to quit รับค่าทิศทางจากผู้เล่น โดยให้ปุ่ม w = เดินขึ้น 1ช่อง a = เดินไปทางซ้าย 1 ช่อง s = เดินลง 1 ช่อง d = เดินไปทางขวา 1 ช่อง และ กำหนดให้ q เท่ากับออกจากเกม.
13. เมื่อกดปุ่ม q ให้ขึ้นข้อความ 'You quit the game.'
14. เมื่อกดปุ่มอื่นที่ไม่ใช้ปุ่มที่กำหนดให้ชึ้นข้อความแจ้งเตือน 'Invalid input! Use w, a, s, or d.'
15. เมื่อเดินเลยแผนที่หรืออกจากจุดที่กำหนดในแผนที่ให้ขึ้นข้อความแจ้งเตือน 'You quit or walked off the field.'
16. เมื่อเดินตกหลุมให้ขึ้นข้อความแจ้งเตือน 'Sorry, you fell in a hole!'.
17. เมื่อเดินไปจนถึงจุดที่หมวกวางอยู่ให้ขึ้นข้อความแจ้งเตือน 'You found your hat!'.
